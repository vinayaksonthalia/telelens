# TELELENS brand

![TELELENS](logo-1200.png)

**The mark.** A camera-aperture diaphragm inside a lens barrel — six blades stopped down
around a clean hexagonal opening held in negative space. It says *lens* (precise, clinical,
optical) without the tired magnifier-and-handle cliché, and the stopped-down aperture is a
quiet visual pun on TELELENS's job: closing the aperture, cutting the excess, focusing
telemetry spend down to what matters. 64×64 grid, 4px barrel stroke, 3.5px blades, single
accent (teal `#14B8A6`) with a subtle same-hue gradient for depth.

**Files.** `icon.svg` (square, 0 0 64 64) is the master mark and works on light and dark
backgrounds. `logo.svg` / `logo-dark.svg` are the horizontal lockups (mark + `TELELENS`
wordmark, Inter 600, +2.4 tracking, all caps) for light and dark surfaces. PNG renders:
`icon-512.png`, `icon-64.png` (transparent), and `logo-1200.png` (on the `#0A0B0D` brand
canvas).

**Usage.** Keep clear space around the mark equal to the aperture opening. Teal is
brand-only — never repurpose it as a severity color (green/amber/red mean status). Use the
icon alone at ≤32px; below 24px the aperture reads as a faceted lens disc, which is intended.
No shadows, no second accent.
